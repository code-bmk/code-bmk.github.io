# code-bmk project homepage

A small static homepage listing selected projects. It has no build step or dependencies.

## Publish with GitHub Pages

This repository is named `code-bmk.github.io`, so its user site is served at `https://code-bmk.github.io/`. In the repository’s **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. The project card links to the separate `shmt` project site at `https://code-bmk.github.io/shmt/`.

The SHMT repository also needs GitHub Pages enabled on its `main` branch and its selected publishing folder. If the GitHub account uses a custom domain, update the card URL to match the actual published site address.
